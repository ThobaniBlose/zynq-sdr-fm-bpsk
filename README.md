# ZedModem — Stage 1: FM Receiver

This branch contains the complete Stage 1 implementation of the ZedModem project — an FM receiver built entirely in FPGA programmable logic on the ZedBoard (Zynq-7010).

The receiver takes a low-IF FM signal from the on-chip XADC, demodulates it in real time, and outputs recovered audio as a PWM signal on an Arduino header pin.

> **Stage 2 (BPSK transmitter)** is on the `stage2-bpsk` branch.  
> **Full project documentation** is on `main`.

---

## Signal Chain

```
XADC (12-bit ADC) → DC offset removal → NCO mixer (downconvert to baseband)
    → 2-tap I/Q LPF → CORDIC atan2 (instantaneous phase)
    → Phase differentiator (FM discriminator)
    → De-emphasis filter (50 µs IIR) → Audio FIR LPF (15 kHz, 63 taps)
    → 4× decimator (200 kS/s → 50 kS/s) → PWM audio output
```

---

## Module Summary

| Module | What it does |
|--------|-------------|
| `adc_center.v` | Subtracts 2048 from the raw ADC code to centre it around zero |
| `nco_mixer.v` | Rotates the signal to baseband using a digital local oscillator |
| `iq_lpf_2tap.v` | 2-tap averaging filter to remove out-of-band mixer products |
| `atan2_phase.v` | Computes instantaneous phase using the Xilinx CORDIC IP |
| `phase_difference.v` | FM discriminator — differences consecutive phase values |
| `deemphasis_filter.v` | First-order IIR de-emphasis with τ = 50 µs (α = 0.905) |
| `audio_lpf_fir.v` | 63-tap symmetric FIR, cuts off above 15 kHz |
| `audio_decimator.v` | Keeps every 4th sample to reduce rate from 200 to 50 kS/s |
| `audio_pwm.v` | Maps 16-bit audio amplitude to an 8-bit PWM duty cycle |
| `xadc_sampler.v` | Reads VAUX1 from the Zynq XADC and pulses `sample_valid` |
| `fm_receiver_hardware_top.v` | Top level — wires XADC sampler into the full receive chain |

## Simulation & Verification

Every module has a self-checking testbench that prints PASS/FAIL to the console. The file-driven testbench `tb_adc_to_fm_demod_file.v` feeds `adc_input_u12.txt` through the full pipeline and compares every output sample against `demod_expected_s16.txt` generated by the MATLAB golden model.

Run any testbench in Vivado XSim by setting the relevant `tb_*.v` as the simulation top.

---

## MATLAB Golden Model

`FM_Demodulation_Golden_Measure.m` simulates the entire FM signal path in floating point — FM modulation, ADC quantisation, digital downconversion, demodulation, and audio filtering. It exports the test vectors used by the Verilog simulation and checks RMSE, max error, and correlation against the reference.

## Hardware Setup (ZedBoard)

| Signal | Pin | Notes |
|--------|-----|-------|
| XADC VAUXP1 | F13 | Differential analog input + |
| XADC VAUXN1 | F14 | Differential analog input − |
| PWM audio out | R8 | Arduino IO0, LVCMOS33 |

The ARM PS7 provides `FCLK_CLK0` at 50 MHz. An inverter in the block design converts the active-low PS reset to the active-high reset the PL expects.
